# ivan-cv-2026

Портфолио Ивана — одностраничник, чистая статика, бэкенда нет.

Стек и раскладка папок взяты с `divodivnoe`, конфиги eslint/prettier/stylelint —
с `face`.

## Стек

- Next.js 16 (App Router) + React 19, React Compiler
- `output: 'export'` — статика в `out/`, раздаётся с GitHub Pages
- SCSS Modules, токены и миксины в `src/styles`
- framer-motion — все скролл-эффекты и парящая карточка

Redux Toolkit, в отличие от `divodivnoe`, не подключён: разделяемого
состояния на странице нет, единственное состояние — позиция скролла,
и она живёт в motion-значениях.

## Запуск

```bash
nvm use          # node 24, см. .nvmrc
npm install
npm run dev      # http://localhost:3000
```

Проверки: `npm run lint`, `npm run lint:styles`, `npm run build`.

## Структура

```
src/
  app/                     layout + страница, порядок блоков
  components/
    ui/                    примитивы: Section, TiltCard, PhoneFrame, ScrollRow
    units/                 Layout
    modules/               девять блоков страницы, по одному на папку
  lib/
    helpers/               шрифты, basePath
    hooks/                 useTilt, useInViewVideo, usePrefersReducedMotion
  styles/                  tokens, mixins, globals
  utils/consts/            весь текст и пути к ассетам
```

## Доступность

Все скролл-эффекты и наклон карточки выключаются при
`prefers-reduced-motion: reduce` — в CSS через миксин `reduced_motion`,
в JS через хук `usePrefersReducedMotion`. Залипающие ленты в этом режиме
превращаются в обычные горизонтально прокручиваемые.
